# Карта кода

Комментариев в самом коде нет — посетители их не видят ни в исходнике, ни в DevTools. Вся навигация здесь.

Быстрый поиск в коде: Ctrl+F по `id` или `class` из таблиц ниже.

## Как устроены тексты
- В `index.html` у элемента стоит `data-i="ключ"`.
- В `i18n.js` у каждого языка (`pl`, `en`, `ru`) есть строка `ключ:"текст"`.
- Меняешь текст → меняй во всех трёх языках. Новый ключ → добавить в pl, en и ru, иначе на другом языке будет пусто.
- Порядок ключей в каждом языке идёт сверху вниз, как блоки на сайте.
- Цифры (100%, 75, 4 h → 0 и т.п.) написаны прямо в `index.html`, не в `i18n.js`.

## Стили (`<style>` в `index.html`)
Идут в том же порядке, что и блоки:
`:root` (все цвета сайта) → общие → `.top` → `.hero`/`.slide`/`.panel` → `.stats` → `.areas` → `.steps` → `.packs` → `.about` → `.faq` → `.cta`/`footer` → `@media (max-width:900px)` планшет → `@media (max-width:600px)` телефон.

Слайдер:
- `.stxt` — текстовая колонка слайда; кнопки прижаты к низу.
- `.acts` — две кнопки одинаковой ширины.
- `.slide > .panel` — карточка справа, одна высота на всех слайдах.

## Скрипт (`<script>` в конце `index.html`)
1. `setLang` — подставляет тексты из `T[язык]`. Язык выбирается так: `?lang=` в адресе → выбор посетителя → язык браузера → польский.
2. `show` / `auto` — слайдер: стрелки, точки, автопрокрутка каждые 7 с, пауза под мышкой.
3. `equalize` — на телефоне выравнивает высоту текста и карточек слайдов по самому большому.
