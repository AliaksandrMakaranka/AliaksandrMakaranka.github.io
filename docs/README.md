# База сайта

Открывается в Obsidian как хранилище (Open folder as vault → папка `docs`).
Это рабочие заметки: на сайт они не ссылаются, но репозиторий публичный, так что секретов сюда не писать.

- [[ideas]] — идеи и план по блокам
- [[done]] — журнал сделанного (дата, что изменили)
- [[rejected]] — от чего отказались и почему, чтобы не повторяться

Тексты сайта на трёх языках лежат в `../i18n.js` — меняем там, не в `index.html`.
